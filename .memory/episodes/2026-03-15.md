# Episode — 2026-03-15

## Context

Integrate the new trigger-association-single-scrape endpoint with the "Process Direct" button on the association detail page (`/dashboard/association/[id]`). The old endpoint (`/api/association/process-direct`) is replaced by `POST /api/association-overview-queues/trigger-association-single-scrape`, which scrapes the association's PlayHQ page and enqueues to `scrape:association-single`.

## Work Done

- Created `src/types/triggerAssociationSingleScrape.ts` (request/response types)
- Created `src/lib/services/data-collection/triggerAssociationSingleScrape.ts` (API service)
- Updated `useProcessAssociationDirect` hook to use `triggerAssociationSingleScrape` instead of `processAssociationDirect`
- Updated `AssociationHeader.tsx` confirmation dialog copy to describe single-association scrape behavior

## Decisions

- None

## Results

- "Process Direct" button on association detail page now triggers the new endpoint
- Success toast shows jobId and queueName; association detail query invalidates on success
- Old `processAssociationDirect` service remains in codebase but is no longer used by the hook
